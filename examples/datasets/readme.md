# Datasets

Copied from [LTNtorch](https://github.com/tommasocarraro/LTNtorch/tree/main/examples/datasets), whose examples these are ported from:

- `iris_training.csv`, `iris_test.csv`: R. A. Fisher's Iris dataset ([UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/53/iris)), split into training and test sets, with the species encoded as 0, 1, 2.
- `crabs.dat`: the Leptograpsus crabs dataset of N. A. Campbell and R. J. Mahon (1974), as distributed with the R package MASS.
- `real-estate.csv`: the Real estate valuation dataset of I.-C. Yeh ([UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/477/real+estate+valuation+data+set)).

MNIST is not included: `examples/4_semi_supervised_pattern_recognition.rb` downloads it into `MNIST/` on its first run.
